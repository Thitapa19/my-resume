Full-Wave Bridge Rectifier & Band-Pass Filter (BPF)

ออกแบบและพัฒนาวงจร Full-Wave Bridge Rectifier และ Band-Pass Filter ออกแบบและจัดทำแผ่นวงจร PCB พร้อมติดตั้งอุปกรณ์อิเล็กทรอนิกส์ ทดสอบและวิเคราะห์การทำงานของวงจรเพื่อให้มั่นใจว่าวงจรสามารถทำงานได้ตามที่ออกแบบ

  • EasyEDA

NeuroGlow — เกมฝึกความจำ

พัฒนาเกมฝึกความจำโดยใช้ภาษา C/C++ ผ่าน Arduino IDE เขียนโปรแกรมเพื่อควบคุมการทำงานของ Arduino Board และอุปกรณ์ที่เกี่ยวข้อง ฝึกทักษะด้าน Embedded Systems, Microcontroller Programming และการพัฒนาโปรเจกต์แบบ Hardware-Software Integration

  • Arduino
  • proteus
  • C++

ระบบจองห้องคาราโอเกะด้วยไมโครคอนโทรลเลอร์ (Karaoke Room Reservation System)

พัฒนาระบบจองห้องคาราโอเกะโดยใช้ ไมโครคอนโทรลเลอร์ PIC16F877A เขียนโปรแกรมควบคุมการทำงานของระบบด้วยภาษา Assembly ออกแบบระบบเพื่อจัดการสถานะและการจองห้องให้เป็นระบบ ลดความผิดพลาดจากการจองซ้ำและการจัดคิว พัฒนาเพื่อเพิ่มความสะดวกและประสิทธิภาพในการจัดการห้องคาราโอเกะ ได้ฝึกทักษะด้าน Microcontroller, Assembly Programming และ Embedded Systems
